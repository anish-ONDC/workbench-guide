# ONDC Protocol Workbench: How It Works

An interactive guide to the ONDC Protocol Workbench: its parts, the checks every message goes through, and three full walk-throughs with real data.

- **How it works**: the parts, the checks, and where data is kept
- **Buyer app test**: your app sends `search`, the workbench replies with `on_search`
- **Seller app test**: the workbench sends `search`, your app replies with `on_search`
- **Playground**: write your own flow in the browser, then run it against a real app

Open `index.html` to start. Plain HTML, CSS and JavaScript; no build step.
